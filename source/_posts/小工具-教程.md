# 关于HTML引入CSS文件后没有效果#

这个问题我想应该是大多数人初次学习前端时经常遇到的问题了，这里整理了一些我遇到的情况

## 1. 路径问题##

<link>标签的href属性的路径有问题，一般情况下建议使用相对路径，写的时候方便，看的时候易懂，一般情况下移动文件不用修改路径。

还有当HTML文件在HTML文件夹内时（PS：假定CSS文件夹与HTML文件夹是同一层），填写相对路径时要先返回上一路径

## 2. type属性问题##

<link>标签可以有type属性，但是type应该写成rel 





如果我要表达不清楚的地方，请移步以下网址：

[关于html引入css文件后没有效果问题_link引入css不起作用-CSDN博客](https://blog.csdn.net/qq_57408330/article/details/128978102)

# Sublime Text运行C和C++程序#

要想Sublime Text可以运行C/C++程序，电脑上要有C/C++的解释器，

检查是否有C/C++解释器，在终端中输入以下命令

```
gcc --version
g++ --version
gdb --version
```

输入后得到以下的输出说明解释器已经配置好了

![png1.png](/img/小工具-教程/png1.png)

如果，没有解释器，可以参考这篇博客添加解释器
